Initial commit: Django backend with REST API and Neo4j integration

This commit establishes the foundational architecture for "Your Media Collection",
a personal media management system with future social features.

## Major Components

### Backend Infrastructure
- Django 5.0.1 with Django REST Framework
- PostgreSQL for structured data (source of truth)
- Neo4j for relationship graph (recommendations)
- Redis + Celery for async tasks and caching
- JWT authentication with SimpleJWT

### Database Models
- Custom User model with UUID primary keys
- Polymorphic Media model supporting:
  * Movies (TMDb integration ready)
  * TV Series (TMDb integration ready)
  * Books (Open Library integration ready)
  * Music (MusicBrainz integration ready)
  * Concerts (user-created)
  * Documents (user-created)
- UserMedia model for collections with status tracking
- SyncTask model for API sync management

### Neo4j Integration
- Complete service layer for graph operations
- Automatic PostgreSQL → Neo4j synchronization via Django signals
- Support for relationships: OWNS, WATCHED, WISHES, IN_PROGRESS
- Constraint and index management

### REST API (20+ endpoints)
- Authentication: register, login, JWT refresh
- User profile: get, update, password change
- Media catalog: list, search, filter by type/genre/year
- Collections: CRUD operations, statistics, timeline
- Full Swagger/ReDoc documentation with drf-spectacular

### Django Apps
- accounts: User management and authentication
- media_catalog: Media models and catalog endpoints
- collections: User collection management
- data_sync: External API integration framework (ready for implementation)
- social: Placeholder for Phase 2 social features
- recommendations: Placeholder for Phase 2 recommendation engine

### Setup & Deployment
- Docker Compose configuration (PostgreSQL, Neo4j, Redis)
- Setup scripts for Linux/macOS/Windows
- Comprehensive documentation:
  * README.md - Project overview
  * QUICKSTART.md - 5-minute setup guide
  * DEPLOYMENT.md - Full deployment instructions
  * API_ENDPOINTS.md - Complete API reference
  * PROJECT_STATUS.md - Progress tracking
- Makefile for common development tasks
- GitHub Actions CI/CD workflow

### Additional Features
- Admin interface for all models
- Django filters for advanced searching
- Pagination support (20 items per page)
- CORS configuration for React frontend
- Security: JWT tokens, password validation, HTTPS-ready
